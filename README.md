# 基于大语言模型的自主移动机器人 Agent 系统

LLM-based Autonomous Mobile Robot Agent System

## 项目简介

本项目实现了一个基于大语言模型的自主移动机器人 Agent 系统。用户可以通过自然语言向机器人下达任务指令，系统能够理解任务、规划行动、调用工具，并在仿真环境中完成任务。

## 技术栈

- **Python**: Agent 程序开发
- **大语言模型 API**: 任务理解与规划
- **ROS 1 Noetic**: 机器人功能管理
- **Gazebo 11**: 机器人仿真环境
- **Navigation Stack**: 自主导航系统

## 项目阶段

### 第一阶段：仿真环境搭建
- 配置 Ubuntu 和 ROS 2 环境
- 启动 Gazebo 仿真
- 加载轮式机器人
- 创建包含墙壁、房间和障碍物的场景
- 实现基本移动控制

### 第二阶段：自主导航
- 地图与定位
- 路径规划
- 障碍物检测与避障
- 导航目标的发送与执行
- 导航状态的读取

### 第三阶段：LLM Agent 接入
- 自然语言任务理解
- 任务分解与规划
- 工具调用
- 执行状态反馈
- 失败重试与任务恢复

### 第四阶段：功能扩展
- 摄像头图像理解
- 语音控制
- 机器人长期记忆
- 动态障碍物处理
- 多任务调度
- Web 控制界面

## 系统架构

```
用户输入 (自然语言)
    ↓
LLM Agent (任务理解与规划)
    ↓
工具调用接口
    ↓
ROS 1 / Navigation Stack (导航执行)
    ↓
Gazebo (仿真环境)
    ↓
状态反馈 → LLM Agent
```

## 核心设计原则

大模型负责思考和规划，ROS 1/Navigation Stack 负责执行具体机器人操作。大模型不直接生成电机控制指令，而是通过工具接口调用导航、查询状态等功能。
